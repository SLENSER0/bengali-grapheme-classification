# Чувствительность интервалов к повторному использованию изображений

Для контраста P2P + GDA минус B2 использованы 281707 наблюдений и 200840 уникальных изображений. В нескольких наблюдениях встречаются 80867 изображений.

В каждой из 1000 реплик байесовского бутстрапа одно случайное значение Exp(1) назначается каждому image_id и используется для всех его появлений. Веса нормируются до исходной численности отдельно внутри каждой графемы, фолда и среза. 95%-е интервалы построены по 2.5-му и 97.5-му процентилям. Они условны на наблюдаемых графемах, разбиении и пяти чекпойнтах с seed 42. Зависимость между результатами разных фолдов из-за общих изображений учитывается через общий случайный вес. Поправка на множественные сравнения не применялась. Seed генератора равен 2026.
