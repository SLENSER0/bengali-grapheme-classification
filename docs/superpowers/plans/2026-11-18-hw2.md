# План ДЗ2. Приоритет классов и форма штрихов на невиданных графемах

План зафиксирован до расчёта результатов ДЗ2. В ДЗ1 ResNet18 дал `main = 0.8751` при `ID = 0.9593` и `OOD = 0.7909`. У корня macro-recall упал с 0.942 до 0.719. В 88.1% ошибок на OOD предсказанная тройка встречалась в обучении. Это позволяет проверить две разные причины ошибки при одном и том же обученном энкодере. [Результаты ДЗ1](../../../results/summary.md) · [Условие ДЗ2](https://github.com/PikaChuChuMF/RnD-ML-Course-2026-2/blob/main/HW_2/HomeWork_2.md)

## Гипотезы и вмешательства

1. **A, Prior2Posterior.** Частоты компонент в обучении сильно различаются, а при подсчёте macro-recall у каждого присутствующего класса равный вес. Предполагаем, что предпочтение частых классов объясняет часть ошибок. Для каждой из трёх голов усредняем её векторы вероятностей на всех обучающих изображениях текущего фолда. Из каждого исходного логита вычитаем логарифм соответствующей средней вероятности. Сила коррекции равна 1. Проверяем изменение общей метрики и recall каждой компоненты. Метод может давать ложные редкие диакритики. [Bhat et al., §4.3, WACV 2025, препринт от декабря 2024](https://arxiv.org/html/2412.16540v1#S4.SS3)
2. **B, признаки двух слоёв по мотивам LE-GDA.** Если последний слой кодирует привычные сочетания штрихов, у промежуточного слоя могут сохраниться признаки формы, пригодные для новой комбинации. Берём среднее по пространству в `layer3` и `layer4` ResNet18. Для каждого слоя и компоненты строим линейный гауссов дискриминант по всем обучающим изображениям фолда. Нормируем признаки и средние классов до единичной длины. К общей внутриклассовой ковариации добавляем единичную матрицу с коэффициентом `trace(S)/D`. Стандартизуем классовые оценки отдельно для каждого изображения и слоя, берём среднее двух векторов и прибавляем его к логитам головы с коэффициентом 1. Переносим формулы (3)–(8) на три обученные головы ResNet18. В статье использованы CLIP, малые размеченные выборки и подбор слоёв и коэффициентов. Здесь слои и коэффициенты фиксируем заранее. Предполагаем рост OOD-recall корня. [Maniamfu et al., октябрь 2026](https://arxiv.org/html/2610.34901v1)

| Вариант | Коррекция A | Дискриминант B | Какое сравнение даёт |
|---|---|---|---|
| B2 | выкл. | выкл. | Воспроизведение исходного результата |
| P2P | вкл. | выкл. | Полная модель без B |
| GDA | выкл. | вкл. | Полная модель без A |
| P2P + GDA | вкл. | вкл. | Полная модель против B2 |

В обеих абляциях удаляется ровно одно слагаемое. При совместном использовании оцениваем prior по исходной голове. Варианты используют одну версию весов и один проход энкодера на изображение. Обучение B2, сумма трёх cross-entropy, шесть эпох, препроцессинг и список изображений общие для четырёх вариантов. Метки валидации доступны только при оценке. Правило предсказания одинаково для знакомых и невиданных графем.

## Что считаем улучшением

Основное сравнение — полная модель против B2, `main = (R_ID + R_OOD)/2`, среднее пяти фолдов при seed 42. Для каждого среза `R = (2·recall_root + recall_vowel + recall_cons)/4`; macro-recall усредняется по классам в истинных метках среза. Правило выбора перенесено из ДЗ1.

- Прирост `main` положителен хотя бы на четырёх из пяти фолдов.
- Нижняя граница парного 95% интервала для Δmain положительна.
- Средний Δmain превышает удвоенное стандартное отклонение B2 по трём seed на фолде 0 (около 0.00481).
- Нижняя граница парного 95% интервала для ΔOOD выше −0.005.

Отдельно приводим результаты обоих одиночных методов. Проверка каждого по тому же правилу помогает интерпретировать абляции. Если комбинация проиграет, показываем и этот результат. В случае отсутствия убедительного выигрыша следующий обоснованный эксперимент — обучающая геометрическая аугментация на тех же фолдах и при тех же шести эпохах. Такой запуск потребует отдельной фиксации условий до измерений.

Описать, какие эффекты выдерживают разброс seed, на каких компонентах и срезах появились исправления и новые ошибки.
